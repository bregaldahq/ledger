# Documentos e Planilhas Internas (Confidencial)

Este diretório é reservado para planilhas contábeis e arquivos de dados reais utilizados em testes locais.

> **Política de Privacidade & Sigilo**:
> Todos os arquivos de dados contábeis (`*.xls`, `*.xlsx`, `*.csv`) dentro desta pasta são estritamente ignorados pelo Git (`.gitignore`), garantindo que nenhum dado real de clientes, CNPJs ou movimentações financeiras seja enviado para o GitHub.
